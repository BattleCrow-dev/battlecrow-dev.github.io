# Портфолио Дмитрия Пашкова

Одностраничный статический сайт: коротко обо мне, контакты и список проектов.

## Структура

- `index.html` — страница и контакты.
- `assets/css/style.css` — стили и адаптация для мобильных устройств.
- `assets/js/main.js` — загрузка и отображение карточек.
- `data/portfolio.json` — список проектов в порядке показа.
- `assets/images/` — фото и обложки. Для Balance Master и CLIMT Play использованы ранее подготовленные PNG-промоматериалы проектов.

Без фреймворков, сборки и серверной логики. Размещение на GitHub Pages сохранено.

## Просмотр

Запустите в папке сайта `python -m http.server 8000` и откройте `http://localhost:8000`.
Список проектов загружается через fetch, поэтому открывать index.html напрямую через file:// не следует.

## Обновление GitHub Pages

Распакуйте архив и перенесите содержимое папки в существующий репозиторий.
Удалите из репозитория старый файл `assets/files/Резюме_Пашков_Дмитрий.pdf`, если он остался после копирования.
Закоммитьте и отправьте изменения обычным способом. Настройки публикации менять не нужно.

Скачивание резюме и ссылка на примеры документации удалены.
